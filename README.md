# Практична робота №5

## Тема
Побудова зображення методом базової точки.

## Завдання
Побудувати зображення методом базової точки.  
Для виконання роботи обрано зображення машинки.

## Мета роботи
Навчитися створювати графічні зображення у C# та Windows Forms, використовуючи метод базової точки.

## Виконання роботи
У середовищі Microsoft Visual Studio було створено програму мовою C#.

У програмі методом базової точки побудовано зображення машинки. Окремі частини машинки розміщуються відносно заданої базової точки.

Зображення складається з:
- кузова машинки;
- кабіни;
- вікна;
- вантажної частини;
- коліс.

## Використані технології
- C#
- Windows Forms
- Microsoft Visual Studio
- Git
- GitHub

## Висновок
Під час виконання практичної роботи №5 було створено зображення машинки методом базової точки. Отримано практичні навички побудови та розміщення графічних об'єктів у Windows Forms.
